## Решения для запусков

**R1 — верное:**

```python
def solve(nums, k):
    seen = set()
    for x in nums:
        if k - x in seen:
            return True
        seen.add(x)
    return False
```

**R2 — неверное, с выводом** (использует один элемент дважды):

```python
def solve(nums, k):
    print("проверяю", nums, k)
    s = set(nums)
    return any(k - x in s for x in nums)
```

**R3 — синтаксическая ошибка** (нет двоеточия в строке 1):

```python
def solve(nums, k)
    return False
```

**R4 — бесконечный цикл:**

```python
def solve(nums, k):
    while True:
        pass
```
