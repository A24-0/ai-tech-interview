# Неверные ответы (ожидаемая оценка: неверно)

1. Кортеж изменяемый, а список нет, поэтому кортеж быстрее копируется.
2. Изменяемые типы это числа, их можно прибавлять, а неизменяемые это списки.
3. Словарь хранит ключи по порядку добавления в отсортированном списке и ищет перебором, ключом может быть любой объект, в том числе список.
4. `yield` завершает программу и возвращает результат наружу, генератор это то же самое, что список.
5. Декоратор это способ удалить функцию из памяти после использования.
6. `is` и `==` одно и то же, просто `is` пишется короче.
7. GIL это графический интерфейс Python, он отвечает за окна.
8. Исключения в Python игнорируются, поэтому программа никогда не падает, `try` нужен только для красоты.
9. `*args` это указатель на память, а `**kwargs` двойной указатель.
10. `a[::-1]` удаляет последний элемент списка.
