# Верные ответы (ожидаемая оценка: верно)

1. Список изменяемый: можно добавлять и менять элементы. Кортеж неизменяемый, поэтому его можно использовать ключом в словаре.
2. Изменяемые объекты меняются на месте, например list, dict и set. Неизменяемые, такие как int, str и tuple, создают новый объект при изменении.
3. Словарь построен на хэш-таблице. Ключ должен быть хэшируемым: у него стабильный hash и корректное сравнение, поэтому обычно это неизменяемые типы.
4. `yield` превращает функцию в генератор, который отдаёт значения по одному и помнит состояние между вызовами. Список хранит все элементы сразу, генератор считает лениво и экономит память.
5. Декоратор это функция, которая принимает другую функцию и возвращает новую, обычно обёртку с дополнительным поведением, например логированием.
6. `==` проверяет равенство значений, `is` проверяет, что это один и тот же объект в памяти.
7. GIL это глобальная блокировка в CPython: в один момент байткод выполняет только один поток. Поэтому потоки не ускоряют вычисления на CPU, но подходят для ввода-вывода.
8. Код в `try`, ошибка перехватывается в `except`, `else` выполняется без ошибки, `finally` выполняется всегда. Необработанное исключение поднимается вверх по стеку вызовов.
9. `*args` собирает лишние позиционные аргументы в кортеж, `**kwargs` собирает именованные в словарь. Так функция принимает произвольное число аргументов.
10. Индекс возвращает один элемент, срез возвращает новую последовательность. `a[::-1]` вернёт копию в обратном порядке.
